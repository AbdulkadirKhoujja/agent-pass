# Naming history and independence

**Current name: Mandovyn.** This repository was originally created on 29 October 2026 under the working name **AgentPass** (GitHub repository slug `agent-pass`). We adopted the name Mandovyn to avoid confusion with an unrelated AgentPass authorization initiative associated with Clerk at https://agentpass.com/.

Mandovyn is independent. It is not affiliated with, sponsored or endorsed by Clerk, the AgentPass initiative, or standards organizations including OpenID, MCP or A2A.

The name is **not a guarantee of trademark clearance**. Domain availability does not establish domain ownership or legal rights. As of initial checks, `mandovyn.com` was reported available by a domain availability provider; no registration is claimed.

Once the repository owner renames the GitHub repository in Settings, the intended canonical location is https://github.com/AbdulkadirKhoujja/mandovyn. GitHub Pages must be reverified after the rename; the current Pages hostname may change. Historical git commits and external links may still refer to the original name, and those historical records should not be falsified.
